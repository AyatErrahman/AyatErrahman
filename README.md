### 🏥 NovaSanté
**A ward for the healers**

An offline-capable Hospital Management System, cast for the Pneumology Department at Rouïba Hospital. Replaces a paper-bound ritual with role-aware records, waiting-list charms, and a full audit trail.

Currently in field testing before it walks the halls for real.

`Electron` `React 18` `Node.js`

**[→ View the incantation](https://github.com/ayat-errahman/novasante-hmis)**

</td>
<td width="33%" valign="top" align="center">

### ✨ Stellar Pattern Classifier
**Reading light from dead stars**

A convolutional model trained to separate true stellar signals from instrument noise — divining candidate variable stars out of raw telescope streams.

Where astrophysics meets deep learning meets patience.

`PyTorch` `NumPy` `Astropy`

**[→ View the incantation](https://github.com/ayat-errahman/sdss-stellar-classification-ml)**

</td>
<td width="33%" valign="top" align="center">

### 🌧️ Rainfall TSAC
**Forecasting the sky's mood**

A hybrid SARIMA + LSTM framework for rainfall prediction — statistics and neural memory working the same spell together to surface seasonal cycles in years of weather data.

`Python` `SARIMA` `LSTM`

**[→ View the incantation](https://github.com/AyatErrahman/Rainfall-TSAC)**
